# RAG 知识库检索技能

## 适用场景
用户想要了解商品知识、退换货政策、购物指南、支付方式说明等商城常见问题时激活此技能。
当问题需要基于知识库内容而非实时业务数据回答时，应优先使用 RAG 工具。

## 触发关键词
- "退换货政策"、"退货流程"、"换货条件"
- "支付方式"、"发票说明"
- "商品使用说明"、"保修政策"
- "配送范围"、"运费说明"
- "会员权益"、"积分规则"

## 工作流程
1. 识别知识咨询意图（区别于商品搜索/下单等操作）
2. 用户已开启 RAG 开关（enable_rag=true）时，RAGMiddleware 自动注入 RAG 工具
3. 根据问题类型选择合适的 RAG 工具：
   - 需要知识库生成答案 → `rag_query`
   - 需要查看结构化实体/关系 → `rag_query_data`
   - 需要探索知识图谱关联 → `rag_graph_search`
4. 用友好亲切的语气整合检索结果，回复用户

## 可用工具

### rag_query(query, mode="mix")
语义检索知识库，返回基于知识库生成的答案和参考来源。

- **query**: 查询文本（至少 3 个字符）
- **mode**: 查询模式（mix/hybrid/local/global/naive，默认 mix）

**返回**：知识库答案文本 + 参考来源列表

### rag_query_data(query, mode="mix")
结构化数据查询，返回知识图谱中的实体、关系和文本块。

- **query**: 查询文本
- **mode**: 查询模式

**返回**：相关实体列表 + 实体关系列表 + 相关文本块

### rag_graph_search(query)
知识图谱搜索，基于查询提取相关实体和关系。

- **query**: 描述要探索的实体或关系

**返回**：知识图谱子图（实体 + 关系）

## 知识库文档（示例）
- 退换货政策
- 支付方式说明
- 配送与运费说明
- 会员权益与积分规则
- 常见商品使用指南

> 知识库文档由运营人员通过 LightRAG WebUI 上传维护。

## 使用示例

### 示例 1：退换货咨询
用户："买的衣服不合适怎么退货？"
→ 调用 `rag_query("退换货政策 退货流程", mode="mix")`
→ 返回退换货政策 + 参考来源

### 示例 2：支付方式咨询
用户："你们支持哪些支付方式？"
→ 调用 `rag_query("支付方式说明", mode="mix")`
→ 返回支持的支付方式 + 说明

## 注意事项
- RAG 工具仅在 `enable_rag=true` 时可用（前端 RAG 开关控制）
- RAG 检索的是知识库内容，不是实时库存/价格；实时数据查询请用商品搜索/详情工具
- 如果 RAG 工具不可用（MCP Server 未启动），Agent 会降级为不使用 RAG，引导用户联系客服
- 回复时语气友好亲切，将知识库的专业内容转化为用户易懂的语言
- 知识库答案附带参考来源，可告知用户"以上信息来源于xxx文档"
