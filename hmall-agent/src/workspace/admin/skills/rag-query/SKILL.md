# RAG 知识库检索技能

## 适用场景
运营人员想要查询运营策略、库存管理指南、订单分析方法、用户分群方法等专业知识时激活此技能。
当问题需要基于专业知识库而非实时业务数据回答时，应优先使用 RAG 工具。

## 触发关键词
- "运营策略"、"库存管理指南"、"订单分析方法"
- "用户分群"、"数据指标解读"
- "秒杀运营"、"促销策略"
- "如何分析..."、"运营指南"、"最佳实践"

## 工作流程
1. 识别知识咨询意图（区别于实时数据查询）
2. 用户已开启 RAG 开关（enable_rag=true）时，RAGMiddleware 自动注入 RAG 工具
3. 根据问题类型选择合适的 RAG 工具：
   - 需要知识库生成答案 → `rag_query`
   - 需要查看结构化实体/关系 → `rag_query_data`
   - 需要探索知识图谱关联 → `rag_graph_search`
4. 整合检索结果与业务数据，生成专业回复

## 可用工具

### rag_query(query, mode="mix")
语义检索知识库，返回基于知识库生成的答案和参考来源。

- **query**: 查询文本（至少 3 个字符）
- **mode**: 查询模式
  - `mix`（默认）：融合知识图谱 + 向量检索，效果最佳
  - `hybrid`：混合 local + global 检索
  - `local`：聚焦具体实体及其关系
  - `global`：提供更宽泛的上下文
  - `naive`：简单向量相似度搜索

**返回**：知识库答案文本 + 参考来源列表

### rag_query_data(query, mode="mix")
结构化数据查询，返回知识图谱中的实体、关系和文本块（不生成最终答案）。

- **query**: 查询文本
- **mode**: 查询模式（同上）

**返回**：相关实体列表 + 实体关系列表 + 相关文本块

### rag_graph_search(query)
知识图谱搜索，基于查询提取相关实体和关系。

- **query**: 描述要探索的实体或关系

**返回**：知识图谱子图（实体 + 关系）

## 知识库文档（示例）
- 秒杀运营策略
- 库存管理指南
- 订单分析方法
- 用户分群方法
- 数据指标解读

> 知识库文档由运营人员通过 LightRAG WebUI 上传维护，Agent 不负责文档管理。

## 使用示例

### 示例 1：运营策略咨询
用户："秒杀活动应该怎么策划？"
→ 调用 `rag_query("秒杀活动策划指南", mode="mix")`
→ 返回知识库中的秒杀运营策略 + 参考来源

### 示例 2：知识图谱探索
用户："库存管理和订单分析有什么关联？"
→ 调用 `rag_graph_search("库存管理 订单分析 关联")`
→ 返回相关实体（库存、订单）及其关系

## 注意事项
- RAG 工具仅在 `enable_rag=true` 时可用（前端 RAG 开关控制）
- RAG 检索的是知识库内容，不是实时业务数据；实时数据查询请用业务工具
- 如果 RAG 工具不可用（MCP Server 未启动），Agent 会降级为不使用 RAG，正常回复业务问题
- 知识库答案附带参考来源，便于运营人员追溯原始文档
