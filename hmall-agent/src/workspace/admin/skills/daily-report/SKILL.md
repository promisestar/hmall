# 运营日报技能

## 适用场景
运营人员想要生成运营日报、查看整体运营数据概览时激活此技能。

## 触发关键词
- "运营日报"
- "生成日报"
- "帮我做一份日报"
- "今日日报"

## 工作流程
1. 识别日报意图（L1 正则匹配或 LLM 理解）
2. 调用 generate_daily_report 工具
3. 工具内部并发调用 5 个查询 API：
   - 订单列表（GET /admin/order/list）
   - 秒杀活动列表（GET /admin/seckill/promotion/list）
   - 秒杀商品关联列表（GET /admin/seckill/relation/list）
   - 商品列表（GET /admin/product/list）
   - 用户列表（GET /admin/member/list）
4. 格式化输出运营日报

## 可用工具
- `generate_daily_report()` — 一键生成运营日报（并发编排 5 个查询）

## 输出格式
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 2026-07-15 枫叶商城运营日报
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【订单概览】
- 订单总数: 156 笔

【秒杀活动】
- 秒杀活动: 3 场
- 秒杀商品关联: 12 条

【商品概况】
- 商品总数: 248 件

【用户概况】
- 用户总数: 1230 人
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 注意事项
- 运营日报需要管理端登录（admin-token）
- 使用 asyncio.gather 并发调用 5 个 API，避免串行等待
- 各 API 请求第 1 页 1 条数据，主要获取 total 总数
- 某个 API 失败时不影响其他数据的展示
