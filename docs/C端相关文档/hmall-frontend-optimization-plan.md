## 二、优先级规划

### P0 — 阻塞购买流程，必须补齐

#### 2.1 商品详情页

**现状**：首页点击商品 → 直接加购，无法查看详情、选择规格。

**目标**：独立详情页 `ProductDetail.vue`。

**功能清单**：
- 商品图片轮播/大图展示
- 商品名称、价格、库存、销量
- 规格/SKU 选择（如有）
- 数量选择器 + 加入购物车按钮
- 商品描述
- （可选）商品评价摘要

**路由**：`/portal/product/:itemId`

**涉及文件**：
- `views/portal/ProductDetail.vue` — 新增
- `api/item.ts` — 可能新增 `getItemById(id)` API
- `types/index.ts` — 确认 Item 类型字段完整性

**工作量**：中（1 个核心页面）

---

#### 2.2 收货地址管理

**现状**：types 已定义 `Address` 接口，但无管理页面。下单时无法选择地址。

**目标**：地址增删改查页面。

**功能清单**：
- 地址列表（默认地址标识）
- 新增/编辑地址表单（姓名、手机、省市区、详细地址、设为默认）
- 删除地址
- 订单确认页引用地址选择

**路由**：`/portal/address`

**涉及文件**：
- `views/portal/AddressList.vue` — 新增
- `views/portal/AddressForm.vue` — 新增（或在列表页内弹窗）
- `api/address.ts` — 已有（确认端点完整性）
- `OrderConfirm.vue` — 修改（集成地址选择）

**工作量**：中（1~2 个页面 + 订单页集成）

---

### P1 — 完善用户体验

#### 2.3 个人中心页

**现状**：顶部栏显示用户名，但没有独立的"我的"页面。

**目标**：聚合入口页面 `UserProfile.vue`。

**功能清单**：
- 用户头像、用户名、余额展示
- 快捷入口：我的订单、收货地址
- （可选）退出登录按钮
- （后续扩展入口：优惠券、收藏、足迹）

**路由**：`/portal/profile` 或 `/portal/user`

**涉及文件**：
- `views/portal/UserProfile.vue` — 新增
- `PortalLayout.vue` — 修改（顶部用户名改为链接跳转）

**工作量**：低（1 个简单页面）

---

#### 2.4 订单详情页 ✅ 已实现（内嵌弹窗）

`OrderList.vue` 中点击订单行 → `el-dialog` 弹窗展示详情（状态、商品清单、金额汇总、时间线）。无需独立路由页面。

### P2 — 增值功能

| 功能 | 说明 | 工作量 |
|------|------|:---:|
| 注册页 | 独立注册页面（目前仅有登录页），支持验证码注册 | 低 |

| 品牌模块 | 品牌列表 + 品牌商品聚合 | 中 |
| 消息通知 | 系统通知列表 | 低 |
| 智能客服 | AI 客服聊天 | 高 |

## 三、实施路线图

```
第一阶段（本周）：P0 — 打通购买全链路
├── 商品详情页（ProductDetail.vue）
│     └── 首页点击 → 详情页 → 加购

│     └── 入口：顶部栏用户名
├── 注册页
│     └── 入口：登录页"去注册"
└── 订单详情页 ✅ 已通过弹窗实现

第三阶段（按需）：P2 — 增值功能
├── 商品评价 + 收藏
├── 浏览足迹
├── 分类浏览
└── 优惠券 / 秒杀（需后端配合）
```

## 四、技术约束

| 约束 | 说明 |
|------|------|
| **框架** | 保持 Vue 3 + TypeScript + Vite + Pinia + TailwindCSS |
| **UI 风格** | 保持现有黑马商城风格（#E4393C 主色、Tailwind 原子类、lucide 图标） |
| **后端依赖** | P0/P1 功能后端 API 已具备（地址 CRUD、商品详情、订单详情）；P2 部分功能（优惠券、秒杀）需后端开发 |
| **路由** | 全部新页面放在 `/portal/` 路径下 |
| **类型** | 复用 `types/index.ts` 现有定义，必要时扩展 |
| **Store** | 地址类可能新增 `stores/address.ts` |
