# 微服务架构电商平台

基于微服务架构实现的电商商城项目，整合服务注册发现、远程调用、网关路由、服务保护、分布式事务、异步通信、搜索引擎等核心技术，构建高可用、易扩展的分布式电商系统。

## 项目架构

项目采用**微服务架构**，拆分为 7 个独立微服务模块，实现业务解耦与模块化开发：

- 购物车微服务
- 网关微服务
- 商品微服务
- 交易微服务
- 支付微服务
- 用户微服务
- 搜索微服务

## 核心技术与实现

### 1. 微服务远程调用

基于 **OpenFeign** 实现微服务间**同步远程调用**，简化服务间接口调用逻辑。

- 典型场景：购物车查询时，远程调用商品微服务获取商品详情信息
- 自动集成负载均衡，基于服务注册信息动态选择服务实例

### 2. 服务注册与配置中心

采用 **Nacos** 作为一站式服务治理平台：

- **服务注册与发现**：所有微服务启动后注册至 Nacos，实现服务自动发现与健康检测
- **配置管理中心**：集中管理微服务配置，支持配置热更新
- **共享配置**：抽取公共配置（如数据库、中间件），减少重复配置
- **动态路由**：网关路由规则配置至 Nacos，监听配置变更实现路由动态刷新

### 3. 统一网关路由

通过**网关微服务**实现前端请求统一入口与管控：

- 请求路由：转发前端请求至对应微服务，屏蔽后端服务地址差异
- 登录认证：基于**JWT 令牌**实现用户登录校验，拦截非法请求
- 用户透传：解析 JWT 令牌，将用户信息附加至请求头传递给下游微服务
- 动态路由：路由配置托管于 Nacos，支持无重启更新路由规则

### 4. 服务保护与容错

集成 **Sentinel** 实现微服务高可用保障：

- 请求限流：控制接口访问频率，防止流量冲击
- 线程隔离：避免单个服务故障耗尽系统资源
- 服务熔断：应对服务依赖故障，快速失败保证系统稳定性

### 5. 分布式事务解决方案

引入 **Seata** 解决微服务分布式事务问题：

- 保证跨多个微服务的数据库操作**原子性**
- 实现业务全局一致性：所有服务操作同时成功，或任一服务失败时全部回滚
- 保障支付、订单、库存等核心业务数据一致性

### 6. 同步 / 异步调用优化

对比分析同步与异步调用优缺点，核心业务同步、非核心业务异步：

- **同步调用**：基于 OpenFeign，适用于核心业务（如商品查询、订单创建）
- **异步调用**：基于**RabbitMQ**消息队列，解耦非核心业务
    
    - 优化场景：支付成功后，异步通知订单服务更新状态，避免同步阻塞
    - 提升系统吞吐量、响应速度与容错能力
    

### 7. 高性能搜索服务

使用 **Elasticsearch** 替代数据库模糊搜索，实现高性能智能搜索：

- 支持品牌、分类、价格多维度过滤查询
- 基于聚合功能实时统计品牌、分类筛选条件
- 自定义算分函数：广告商品权重加权，实现推广商品优先展示
- 提升搜索响应速度与查询精准度，优化用户搜索体验

## 项目亮点

1. 完整微服务技术栈落地，覆盖服务治理全流程
2. 同步 + 异步结合的服务调用方案，平衡业务一致性与系统性能
3. 动态配置、动态路由，适配生产环境灵活变更需求
4. 多层服务保护机制，保障系统高可用
5. 分布式事务解决方案，解决微服务数据一致性难题
6. 搜索引擎优化，提升电商核心搜索功能体验
